# instafluencer-clips

Warteschlange KI-generierter Clips (gekennzeichnet) fuer automatisches Posten. Dateien liegen als Release-Anhaenge im Release `clips` und werden nach dem Posten entfernt.

## Stimmen der Figuren (Higgsfield)

Für Off-Stimmen (`text2speech_v2`) und Stimmwechsel (`voice_change`) immer diese Preset-Stimmen verwenden (`voice_type: preset`):

| Figur | Stimme | voice_id |
|---|---|---|
| Mila | Nadine | `165d9309-bb17-56ff-964a-5d6a38dab92f` |
| Nele | Skye | `1fb253b8-928b-4d29-a349-f242a71eaddf` |
| Hilde (läuft aus) | Petra | `0c63637d-2ecb-5bda-9bbe-38894aa9a876` |

Quelle: Higgsfield-Audio-Historie, alle B-Roll-Off-Stimmen seit Mitte Oktober 2026. Higgsfield speichert beim Stimmwechsel die Stimme nicht, deshalb hier festgehalten.
Ausnahme: `mila-2026-11-24-01` (Posting 23.11.2026) ist mit Naomi vertont.
